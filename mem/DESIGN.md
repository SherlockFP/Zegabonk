# ZEGABONK design contract

Original names/art. Clone the dopamine architecture, not MEGABONK content.

## Feel every 30s

Weak start -> XP/loot on the ground -> RNG cards that serve the build -> visibly stronger attacks -> density ramps with the player -> boss as a build check -> death -> instant retry.

Player power should outrun density. Never "the game punished my growth 1:1".

## GAMEPLAY

Dopamine about every 30s: weak start -> XP/loot on the ground -> 3 cards that serve the build -> attacks visibly stronger -> density ramps with player LEVEL/power (never a wall at second 10) -> boss as a build check -> death -> instant retry.

Power curve: ~1x at open, ~10x mid, ~50x late. Player power outruns density.

Layers:
- Silah: attack pattern, max 4
- Tomar: named global books only (Bonk / Ruzgar / Can / Cekim / Kabuk / Bilgi), max 4 slots
- Esya: build enabler, not a flat +10
- Olay: one-shot world event
- Character: bias, not a lock

Opening: 1-2 fodder, slow CD. After ~50s, spawn count follows level.

## Map = combat geography

Not a giant flat disc. Not a Diablo corridor.

- ~65% open kite space
- ~20% narrow / tree-belt traversal
- ~15% POI (chest, shrine, elite bowl, later portal)

Each region has one readable landmark. Centerpiece is a broken meteor, not a fake portal. Decor rings arenas; interiors stay 360-moveable.

Environment stays quieter than player / enemies / XP / VFX.

## Do not

Copy MEGABONK characters, weapons, items, UI, bosses, maps.
Permanent +500% damage. Giant empty 20km planes. Cover spam around the player.
