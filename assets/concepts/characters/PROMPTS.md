# Generation Prompt Set

All six files were generated with the built-in image generation tool. The shared production prompt was:

```text
Use case: stylized-concept.
Asset type: production character turnaround sheet for Blender modeling in the ZEGABONK browser game.
Create one entirely original, teen/family-friendly bright dark-fantasy character with chunky exaggerated proportions, a clean combat silhouette, low-poly-friendly forms, semi-realistic hand-painted materials, and no resemblance to an existing game character.
Show the same subject as full-body orthographic front, strict left side, and exact back views at identical scale on one baseline. Add only useful head and equipment closeups. Use a plain warm light-gray studio background and flat neutral modeling light.
Keep all clothing, anatomy, colors, and proportions consistent between views. No environment, perspective hero pose, text, labels, UI, logo, or watermark. Avoid photorealism, anime, chibi treatment, gore, horror, thin fragile limbs, ornate microdetail, and view-to-view drift.
```

Subject-specific additions:

- Crownrunner: young adult adventurer, navy mantle, warm leather, teal accents, crown clasp, oversized turquoise crystal hammer.
- Rattlecap Runner: compact moss-green forest raider, triangular leaf hood, wooden mask grin, short cleaver with a cyan crystal chip.
- Sunscar Bulwark: broad sandstone beetle-ogre guardian, round bronze-and-wood shield, orange cloth, amber eyes.
- Crownwing Skimmer: indigo magical manta-bat air unit, wide turquoise wing membranes, gold hornlets, crystal-tipped ribbon tail.
- Riftcap Hexer: violet mushroom-sage caster, teal bark mask, layered bark cloak, turquoise crystal-ring staff.
- King Grom: huge stone-and-cloud royal tyrant, floating broken gold crown, storm-blue fissures, purple cloth, oversized mace, carved moustache, dramatic but lightly comedic arrogance.
