# UI concept sheets

These are visual-direction references for Zegabonk V2 UI. They are not shipped UI backgrounds and must not own runtime copy, interaction, accessibility state, or layout. The runtime must render all labels, controls, focus states, and values as DOM.

## V2 direction

- `zegabonk-ui-concept-hero-select-v2.png`: hero selection. Keep the daylight citadel, four clean class silhouettes, a cyan selected-state edge, and one obvious gold primary action.
- `zegabonk-ui-concept-settings-terminal-v2.png`: settings. Keep the compact left rail, grouped control rows, cyan adjustable controls, and a bright world-preview card.

Shared language: chunky low-poly fantasy, daylight cyan, warm gold, small violet accents, dark navy glass panels, generous readable spacing, and playful tactile focus. Do not copy text or individual pixels from either image.

## Runtime handoff

1. Use the sheets for hierarchy and palette only.
2. Keep gameplay visible behind pause/settings where practical; blur and darken it lightly instead of replacing it with a static image.
3. Every click target needs hover, press, focus-visible, disabled, and reduced-motion behavior in code.
4. UI art must stay original. These concepts contain no external game branding or borrowed logos.
