Use an information hierarchy with a bold title zone, four selectable hero cards, one center-stage selected hero, a primary start action, and compact profile panel. No logo, game name, copied branding, or required readable text. Backdrop: sunny floating-island citadel plaza, crystalline ruins, distant violet rift tower, blue sky and soft clouds. Characters: teal hammer knight, shadow ranger, violet rune caster, stone guardian. Use premium in-engine menu concept art, dark navy translucent panels, cyan and warm-gold focus glow, and light violet magic accents. Bright, adventurous, teen-friendly, and non-photorealistic.

## settings-terminal-v2

Create an original polished settings screen for a bright low-poly fantasy action roguelite. Use abstract icons and decorative glyphs only: no logo, game name, or required readable text.
